# Chapter 10: Written Presentation of Pyramid Structure

## Core Idea

Format written documents to reveal pyramid structure visually. Readers should grasp your entire thesis, supporting points, and key evidence within 30 seconds by skimming headings and formatted text.

## Frameworks Introduced

### 1. **Five Formatting Methods for Visualizing Structure**

Each method makes pyramid levels visually distinct:

**Method A: Multi-Level Headings (多级标题法) — RECOMMENDED**
- Level 1: Chapter title (left-aligned, bold)
- Level 2: Section title (indented, smaller font)
- Level 3: Subsection title (further indented, even smaller)
- Level 4+: Numbered paragraphs or bullets

**Advantages:**
- Can serve as table of contents
- Fastest visual scanning
- Easy to revise
- Professional appearance

**Method B: Underlining (下划线法)**
- Underline key sentences (thesis, main points, sub-points)
- Vary font size/weight with indentation for hierarchy
- Useful for medium-length documents

**Method C: Numerical Indexing (数字编号法)**
- Number all major points (1, 2, 3...)
- Use sub-numbering (1.1, 1.2 or I.A.1, I.A.2)
- Best for: Policy documents, specifications, contracts
- Drawback: Creates distance between headings and meaning

**Method D: Line Indentation (行首缩进法)**
- Use indentation (no headers) to show hierarchy
- Good for short documents
- Limited readability for long documents

**Method E: Bullet Points (项目符号法)**
- Variant of line indentation
- Use bullets at each level, varying style
- Excellent for executive summaries, progress reports

### 2. **Six Rules for Effective Headings (标题六原则)**

**Rule 1: Never Have Only One Heading at Any Level**
- If you have 1 chapter, you have none
- Headings represent pyramid levels
- Each level must have 2+ items
- Don't use headings merely for visual breaks

**Rule 2: Use Parallel Structure (并列结构)**
- All headings at same level should match grammatically
- If first heading starts with verb, all should start with verbs
- If first heading is noun phrase, all should be noun phrases
- Creates visual rhythm and shows logical grouping

Example:
```
ACCEPTABLE (parallel):
- Implement preventive maintenance
- Expand testing capacity
- Improve product quality

POOR (non-parallel):
- Implement preventive maintenance
- Testing capacity expansion needed
- Improving product quality
```

**Rule 3: Make Heading Words Convey Core Idea**
- Heading should capture essence of supporting text
- Short, punchy, not complete sentences
- Include key nouns/verbs that carry meaning
- Avoid vague labels like "Key Findings" or "Important Results"

**Rule 4: Separate Heading from Body Text**
- Heading is hook for attention (eye-scanning)
- Body is for comprehension (mind-processing)
- First sentence after heading shouldn't restate heading
- Article should read smoothly even if headings removed
  (Exception: Numbered paragraphs, where heading is part of the text)

**Rule 5: Introduce Each Set of Headings**
- After major heading, add paragraph explaining what follows
- Prevents reader confusion about relevance
- Telegraphs the main argument
- Don't jump immediately to sub-headings

**Rule 6: Don't Overuse Headings (关键原则)**
- Only use headings when they help communication
- Excessive headings fragment attention
- Headings should reveal logical structure, not break text randomly
- Quality over quantity

### 3. **Transitions Between Sections**

**The Four Transition Techniques:**

**A. Narrative Bridge (讲故事)**
Use Situation-Complication-Question format to lead into next major point:
```
Background: Current market position is strong
Complication: But competitors are entering our segment
Question: How should we respond?
[Next section answers: "We should..."
```

**B. Connective Flow (承上启下)**
Start new section by referencing previous section's key word/phrase:

Previous section ends: "...so we need three structural reforms"
Next section begins: "These structural reforms must address three key areas..."

**C. Part Summary (小结)**
For long/complex chapters, summarize before moving forward

**D. Conclusion + Transition**
End with thesis + bridge to what's next

## Key Concepts

**Visual Hierarchy**
- Pyramid structure exists in readers' minds because they can SEE it on page
- Indentation, font size, boldface all communicate levels
- Reader should never guess relationship between ideas

**30-Second Rule**
- A reader skimming headings should grasp entire argument
- Test: Read only headings (no body text) — argument should be clear
- If headings alone don't make sense, restructure

**Heading as Miniature Thesis**
- Each heading should be a complete thought
- "Problem identified" vs. "Identify Problem" — first is stronger
- Heading should propose, not merely name

**Consistency Over Appearance**
- Format matters less than consistency
- Whatever system chosen must apply uniformly
- Reader learns quickly to interpret your style

## Worked Example

**Weak Version** (No clear structure):
```
Introduction
We analyzed three quarters of sales data and found interesting 
patterns. Our regional teams are performing differently, and 
market conditions vary by geography. Also, we noticed customer 
retention varies significantly. Price sensitivity differs too.
The question is what we should do about this.

Background on Methods
We collected data in the following way...
```

**Strong Version** (With structure revealed):
```
Three Actions Will Restore Profitability
To address our regional sales decline, we recommend:
1. Implement localized pricing strategy
2. Strengthen customer retention programs  
3. Reallocate sales resources to high-growth markets

Action 1: Localized Pricing Strategy
Current state: Regional margins vary 15-40%
Required state: Achieve uniform 35%+ margins

The problem: Competitors undercut us in price-sensitive markets
The solution: Implement region-specific pricing based on competitor analysis

Required steps:
a) Analyze competitor pricing by market
b) Adjust our pricing (likely decrease in price-sensitive regions, 
   increase in premium markets)
c) Test with pilot regions before full rollout

Expected result: Close pricing gaps, recover 5% margin pressure
```

## Key Takeaways

1. **Format reveals logic** — Effective formatting isn't decoration; it's communication
2. **Consistency enables scanning** — Uniform formatting lets readers navigate quickly
3. **Headings are arguments** — Each heading should state a meaningful claim, not just label
4. **Hierarchy must be visual** — Reader's eye should immediately grasp levels
5. **Introduce then deliver** — Each set of headings needs introductory paragraph
6. **One style per level** — Don't mix formatting styles for same hierarchy level
7. **Less is more** — Overusing headings/formatting dilutes effectiveness
8. **Test the 30-second rule** — Headings alone should convey full argument

## Anti-Patterns

- Don't use headings like "Introduction," "Background," "Analysis," "Findings" (labels, not arguments)
- Don't create single headings at any level (violates pyramid structure)
- Don't use non-parallel heading structures (inconsistent creates cognitive load)
- Don't let first sentence of body repeat heading (waste of space)
- Don't jump to sub-headings without introductory paragraph to main heading
- Don't format more than 3-4 hierarchy levels (creates visual chaos)
